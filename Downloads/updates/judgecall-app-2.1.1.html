JudgeCall 2.1.1

Android · APK · 正式版本

JudgeCall 2.1.1 正式发布。本次更新引入全新的 IBIS 规则搜索引擎，并新增规则条目图片分享功能，同时对计时工具、文档结构、图标显示及应用界面进行了全面优化。

安装前必读

新版无法直接覆盖旧版本

本次更新使用了新的应用签名，无法直接覆盖安装旧版本。

安装 JudgeCall 2.1.1 前，请务必先卸载原有版本，再安装新版 App。卸载应用可能会清除原版本中保存的本地数据，请提前导出或备份重要记录。

01

文档更新

  • 新增 Mastery Pack: Warrior Release Notes。
  • 新增将于 2026 年 9 月 25 日生效的 Errata Bulletin 相关内容。

02

功能更新

全新 IBIS 规则搜索引擎

重构原有搜索逻辑，为 JudgeCall App 开发全新的 IBIS 规则搜索引擎，进一步提升规则检索的准确性、响应速度与使用体验。

IBIS：Identify. Browse. Interpret. Solve.

新增规则条目分享功能

长按各规则文档中的条目，即可自动生成适合分享的规则图片。生成后的图片可以：

  • 保存至本地；
  • 分享至社交媒体、聊天软件或其他 App；
  • 保留规则正文及对应来源，方便裁判与玩家快速交流。

调整 Timer 功能

删除原有的单纯计时功能，改为点击记录时间节点，并自动计算相邻两次点击之间的时长，为赛事中的补时判断和时间记录提供参考。

03

问题修复

  • 完善 Chi（{c}）、Tap（{t}）和 Untap（{u}）三个图标的显示效果；
  • 修复数据库中的部分编码识别错误；
  • 修复规则条目来源与规则正文重复显示的问题；
  • 调整 Release Notes 的展示结构，现按产品分类显示，不再以独立条目形式排列。

04

其他更新

  • 更新 JudgeCall App Logo 及开屏页面；
  • JudgeCall 官方网站已于 8 月 10 日上线，可通过 About 页面一键访问；
  • 得益于搜索逻辑和数据结构优化，App 安装包体积较上一版本缩小近 30%。

JudgeCall 2.1.1 is now available. This release introduces the new IBIS rules search engine and rules-entry image sharing, together with broad improvements to the timer, document structure, icon rendering, and app interface.

BEFORE INSTALLING

This version cannot replace an older installation

This release uses a new app signing key and cannot be installed over an older version.

Before installing JudgeCall 2.1.1, uninstall the existing version and then install the new app. Uninstalling may remove locally saved data, so export or back up important records first.

01

Documentation

  • Added the Mastery Pack: Warrior Release Notes.
  • Added content from the Errata Bulletin taking effect on September 25, 2026.

02

New Features

All-new IBIS rules search engine

The original search logic has been rebuilt around JudgeCall's new IBIS rules search engine, improving accuracy, response speed, and the overall rules-lookup experience.

IBIS: Identify. Browse. Interpret. Solve.

Share rules entries as images

Press and hold an entry in any rules document to generate a share-ready image. The image can:

  • Be saved locally;
  • Be shared to social media, messaging services, or other apps;
  • Preserve both the rules text and its source for fast communication between judges and players.

Updated Timer

The basic stopwatch has been replaced with timestamp recording. Tap to record each point, and JudgeCall automatically calculates the time between consecutive taps as a reference for extensions and tournament timekeeping.

03

Fixes

  • Improved rendering for the Chi ({c}), Tap ({t}), and Untap ({u}) icons;
  • Fixed several character-encoding recognition errors in the database;
  • Fixed duplicated rules text and source information;
  • Reorganized Release Notes by product instead of presenting each as a separate entry.

04

Other Updates

  • Updated the JudgeCall App logo and splash screen;
  • The official JudgeCall website went live on August 10 and is now available directly from the About page;
  • Search and data-structure optimizations reduced the installer size by nearly 30% compared with the previous release.
