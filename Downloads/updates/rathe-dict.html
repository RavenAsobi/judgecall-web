UPDATE LOG · 02

Rathe Dict v3.0.3

2026-10-08 · Android 8.0+ · 约 23.9 MB

更轻的安装包、更灵活的卡图下载，以及无需重新安装的卡牌与释疑更新。Rathe Dict v3.0.3 现已收录 IAR Release Note，并整合本轮浏览体验改进。

01

更轻的安装包，按需下载卡图

  • 首次安装即包含完整卡牌文字数据库与已收录的规则释疑，不捆绑卡牌图包。文字查询可离线使用，卡图按需下载后可离线查看。
  • 在 About 中选择需要的系列图包；系列按卡牌编号开头的 3 个字母划分。新增 Select All（一键全选），便于批量下载尚未更新的图包。
  • 本次版本包含 5,216 个卡牌条目、18,582 个印刷条目；服务器提供 125 个系列图包。卡牌数据与图片已根据官方 Card Vault 资料更新。

02

卡牌、Release Note 与关联一起更新

  • 在 About → Check updates 检查服务器发布的内容，再下载数据更新，即可获得新增卡牌、Release Note 和单卡关联，无需为了新增内容重新安装 App。
  • 即使卡牌数量没有变化，说明正文或单卡关联发生变化也可以发布更新。安装更新前会校验数据完整性和关联有效性，收藏与个人清单保留。
  • 内容由维护者整理并发布到服务器后提供下载；App 不会自动抓取官网。图包仍可单独选择下载。

03

新增 Usurp the Shadow Throne（IAR）释疑

  • 收录本次提供的完整 IAR Release Note，整理为 167 条说明，建立 308 条关联，覆盖 257 个卡牌条目。在对应单卡详情中即可查看相关说明。
  • 同时保留文档中的新机制、Malice Armory Deck 与 Token 说明，以及已有系列的释疑和关联。
  • 修正本次发现的 AUA001–AUA029 编号：这些卡图上误印为 ARA，数据库使用正确的 AUA；原本属于 ARA 的卡牌保持不变。

04

浏览与版本选择更清晰

  • Vault 改为每行一张卡牌的列表布局，左侧显示缩略图，右侧左对齐显示卡名。
  • Printings 改为下拉列表；搜索和预览优先展示已下载图片中编号最靠前的版本。详情页默认采用同样的选择，手动选择版本后保留该选择。
  • 已下载状态使用圆圈对号图标，系列名称中的 Unlimited 简写为 UNL。精简 About 的解释文字与排版。

05

缺图时可直接下载整个系列

  • 所有缺图占位统一改为 Flesh and Blood Logo。
  • 在详情页点击缺图占位图，即可选择 Confirm 下载对应系列的完整图包，或选择 Cancel。
  • 勾选 Do NOT ask again today 后点击 Cancel，当天将不再弹出下载询问；按设备本地时间，在次日 00:00 恢复。仍可随时在 About 中主动下载图包。

06

如何获取本次更新

  • 新用户可直接下载 v3.0.3，其中已内置本次卡牌文字与 IAR 释疑；按需下载卡牌图片。
  • 已使用支持内容更新的版本，可先在 About 中下载约 6.4 MB 的本次数据库更新。安装 v3.0.3 还可获得新版更新提示与关联校验。
  • 本篇合并记录 v3.0 至 v3.0.3 的主要更新。查看 v2.0 历史日志。

A smaller download, optional card artwork, and card and ruling updates without reinstalling. Rathe Dict v3.0.3 includes IAR Release Notes and the browsing improvements from this update cycle.

01

A smaller install, with images on demand

  • The initial installation includes the complete card text database and the rulings collected so far, without bundled card image packs. Text lookup works offline, and downloaded images remain available offline.
  • Choose image packs in About. Packs are grouped by the first three letters of the card number. The new Select All control selects packs that are not already current for bulk download.
  • This release includes 5,216 card entries and 18,582 printing entries, with 125 set image packs on the server. Card data and artwork have been updated using official Card Vault information.

02

Update cards, Release Notes and card links together

  • Use About → Check updates, then download the published data update to receive new cards, Release Notes and their card associations, without reinstalling the App for new content.
  • Updates can include changes to note text or card associations even when the card count stays the same. The App validates data integrity and associations before installation, while preserving favorites and personal lists.
  • Content becomes available after the maintainer reviews and publishes it to the server; the App does not automatically scrape the official website. Image packs remain optional, separate downloads.

03

Usurp the Shadow Throne (IAR) rulings

  • The supplied IAR Release Note is included in full, organized into 167 entries with 308 associations across 257 card entries. Relevant notes are available from each linked card’s detail page.
  • New mechanics, Malice Armory Deck and Token notes from the document are included. Existing notes and associations from other sets are preserved.
  • Corrected the affected AUA001–AUA029 entries: their artwork incorrectly prints ARA, while the database uses the correct AUA code. Cards that genuinely belong to ARA remain unchanged.

04

Clearer browsing and printing selection

  • Vault now uses one card per row, with a thumbnail on the left and a left-aligned card name on the right.
  • Printings uses a dropdown. Search and previews show the lowest-numbered printing with a downloaded image. Card details use the same default and retain a printing selected manually.
  • A circled checkmark indicates downloaded content. Unlimited is abbreviated to UNL in set names. About has a cleaner layout with less explanatory text.

05

Download a set from a missing-image placeholder

  • All missing-image placeholders now use the Flesh and Blood logo.
  • Tap a missing image on a card’s detail page to download its complete set image pack with Confirm, or dismiss with Cancel.
  • Select Do NOT ask again today and press Cancel to suppress download prompts until the next local midnight on the device. Downloads remain available in About at any time.

06

Get this update

  • New users can download v3.0.3 with the updated card text and IAR notes already included, then choose which card image packs to download.
  • Users of an existing version that supports content updates can get the approximately 6.4 MB database update from About. Installing v3.0.3 also provides the updated status messages and association validation.
