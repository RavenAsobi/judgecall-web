Rathe Dict v2.0

Android · APK · 正式版本

Rathe Dict v2.0 带来了全新的 MyList 清单系统、R2D 离线分享机制、卡图分享功能，并进一步完善搜索逻辑、符号显示与整体 UI 体验。

安装前必读

请先卸载现有的 1.X 版本

安装 Rathe Dict v2.0 前，请先卸载现有的 1.X 版本。

为避免旧版本数据结构与 v2.0 产生兼容性问题，不建议直接覆盖安装。

01

数据更新

  • 离线卡牌数据库已更新至 Mastery Pack: Warrior。
  • 离线卡图资源已同步更新至 Mastery Pack: Warrior。
  • Release Notes 数据已同步更新至 Mastery Pack: Warrior。

02

功能更新

全新 MyList 功能

新增 MyList 清单系统，可用于快速创建和管理自定义卡牌清单。目前支持：

  • 创建、编辑和管理多个 List；
  • 为清单中的单卡指定具体印刷版本；
  • 将完整 List 生成图片并分享；
  • 将 List 生成 R2D 码，便于快速分享；
  • 支持读取他人分享的 R2D 码导入 List；
  • R2D 码无需联网即可完成数据传递与导入，适用于网络环境不稳定的场景。

卡图保存与分享

在单卡页面中长按卡图，即可将卡图保存至本地或直接分享到其他应用。

搜索逻辑升级

进一步丰富搜索关键词识别逻辑，对常见缩写、简称及模糊搜索进行自动匹配。例如搜索：

cncpopperwarrior chest

Rathe Dict 将尝试自动识别对应卡牌，减少输入完整卡名的需要，让移动端查询更加快速。

03

问题修复与体验优化

  • 完善各类游戏符号的映射与显示。
  • 修复收藏按钮在未选中状态下图标显示错误的问题。
  • 优化搜索结果页面返回逻辑：从搜索结果进入单卡详情后再次返回，将恢复至此前浏览位置，不再自动回到列表顶部。
  • 修复 True Text 中部分 Markdown 语法校验及显示异常。
  • 移除开发过程中误显示的冗余信息。
  • 优化并统一 App 各页面 UI 视觉与交互逻辑。
  • 优化 Filter 功能，将筛选条件调整为折叠式选项，使界面更加简洁。

04

待开发内容

Filter 中已预留 Pitch Color: Purple 筛选选项。

该功能将在 IAR 系列官方图库及 Release Notes / 发售释疑资料更新后正式投入使用。

Rathe Dict v2.0 introduces the new MyList system, offline R2D sharing, and card-image sharing, together with improvements to search, symbol rendering, and the overall interface.

BEFORE INSTALLING

Uninstall any existing 1.X version first

Before installing Rathe Dict v2.0, uninstall your current 1.X version.

Installing over the previous version is not recommended because its data structure may be incompatible with v2.0.

01

Data Updates

  • The offline card database now includes Mastery Pack: Warrior.
  • Offline card images have been updated through Mastery Pack: Warrior.
  • Release Notes data has been updated through Mastery Pack: Warrior.

02

New Features

All-new MyList

The new MyList system lets you quickly create and manage custom card lists. It currently supports:

  • Creating, editing, and managing multiple lists;
  • Selecting a specific printing for each card;
  • Generating a shareable image of a complete list;
  • Generating an R2D code for quick sharing;
  • Importing a list from someone else's R2D code;
  • Transferring and importing R2D data entirely offline, ideal when connectivity is unreliable.

Save and share card images

Press and hold a card image on its detail page to save it locally or share it directly with another app.

Upgraded search

Search now recognizes more common abbreviations, short names, and fuzzy queries. For example:

cncpopperwarrior chest

Rathe Dict will try to identify the matching card automatically, reducing the need to enter a full card name and making mobile lookup faster.

03

Fixes and Experience Improvements

  • Improved mapping and rendering for game symbols.
  • Fixed the incorrect icon shown when the favorite button was not selected.
  • Improved back navigation from card details so search results return to the previous scroll position instead of the top.
  • Fixed Markdown validation and rendering issues in True Text.
  • Removed redundant development information that was shown unintentionally.
  • Refined and standardized interface visuals and interactions throughout the app.
  • Changed Filter options to collapsible groups for a cleaner interface.

04

Coming Later

A Pitch Color: Purple option is already reserved in Filter.

It will become available after official IAR-series card images and Release Notes / release clarification materials are published.
