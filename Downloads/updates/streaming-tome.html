UPDATE LOG · 03

Streaming Tome v1.2 beta

Windows 10 / 11 · EXE · Beta 版本

Streaming Tome v1.2 Beta 聚焦于卡牌内容扩充、直播画面易读性、品牌统一和现场操作效率。在保留本地运行、局域网 Life Tracker 与 OBS Browser Source 工作方式的基础上，进一步完善比赛控制、卡牌展示和多语言选手姓名支持。

版本信息

2026 年 8 月 20 日发布

适用平台：Windows 10 / Windows 11。软件继续坚持离线优先与局域网运行原则，比赛状态不会上传或持久化到外部服务。

01

版本亮点

  • MPW 与 AOL 系列卡牌内容已整合进本地卡库。
  • Match Overlay 的英雄头像、生命值、计时器和左右对称布局全面优化。
  • 卡牌文字现可正确解析 Markdown，并显示 Flesh and Blood 属性图标。
  • 软件品牌视觉已统一，桌面窗口、网页、EXE 与任务栏均使用新版 logo。
  • Card Reference Console 改为按需加载，软件启动更轻量。
  • Match Control 与 Overlay 现可正确显示中文、日文、韩文等非英文选手姓名。

02

卡牌内容更新

MPW 与 AOL 系列

两个系列的卡牌数据与卡图已按照现有离线卡库标准完成更新和整合，可用于 Card Reference Console 搜索、独立卡图展示、本地卡牌文字查询，以及英雄选择与 Match Overlay 头像显示。

当前本地数据库包含 2,926 条卡牌记录，并已完成缺图、无效文件与重复记录检查。软件完全使用本地数据，不需要连接外部卡牌 API。

英雄头像显示优化

Overlay 中的英雄头像现在会以正方形区域显示并自动截取卡图主体，不再露出卡牌边框、名称或其他文字信息，使直播画面更接近正式赛事转播风格。

03

Match Control 与直播 Overlay

生命值区域重新设计

  • 原有的 HP 文字已替换为 Health 图标，并按左右玩家方向分别放置。
  • 图标与生命值数字保留清晰间距；移除区域边框并扩大可用空间，降低数字被遮挡或裁切的风险。
  • 比赛记录位置同步向两侧调整，使左右玩家信息保持轴对称。
  • 修复生命值变化动画放大时超出显示区域的问题。

计时器与布局

放大 ROUND TIMER 标签字号，提高远距离观看时的辨识度；保留原有计时、加时、Untimed Round、主题、自定义颜色与尺寸调整功能。

多语言选手姓名

中文、日文、韩文及其他非英文姓名会自动切换为“微软雅黑”，避免缺字或方框；纯英文姓名仍使用原有字体。字体选择在 Overlay 缩放、主题切换和比赛状态同步后仍会正确保留。

04

卡牌文字显示

Markdown 解析修复

卡牌规则文字现可正确显示标题、斜体与粗体等常用 Markdown 格式。

Flesh and Blood 属性图标

规则文字中的属性标记会转换为对应图标，并与文本基线对齐，适用于英文及本地翻译内容（本地翻译内容待更新）。

{h} Health{p} Power{i} Intellect{d} Defense{t} Tap{u} Untap{c} Chi{r} Resource

05

品牌视觉更新

新版 Streaming Tome logo 已应用至 Match Control、Card Reference Console、卡牌文字窗口、网页 Life Tracker、浏览器页签、Windows 窗口与任务栏，以及最终发布的 EXE 文件。

深色界面使用白色圆角矩形地衬以保持对比；Card Reference Console 中的 logo 调整为更紧凑的尺寸。Windows 运行时图标与 EXE 内嵌图标使用同一品牌资源和新的应用身份配置，减少任务栏继续显示旧图标的情况。

06

启动与窗口操作改进

Card Reference Console 按需加载

软件启动时默认只打开 Match Control。卡牌数据库、翻译表和 Card Reference Console 相关窗口会在首次点击 OPEN CARD CONSOLE 时加载，减少启动阶段不必要的初始化工作。

独立窗口开关

  • 关闭 Card Reference Console 不再关闭整个程序或停止 Life Tracker。
  • 可通过 Match Control 随时重新打开；若窗口已打开或最小化，按钮会将其恢复至前端。
  • Card Reference Console 中仍可使用 OPEN LIFE TRACKER 返回 Match Control。

07

稳定性与兼容性

  • 保留现有 LAN Life Tracker、WebSocket 同步和 OBS Browser Source 地址格式。
  • 保留 Overlay 透明背景、16:1 比例、Always on Top 与自定义尺寸功能。
  • 网页静态资源加入版本标识，覆盖升级后会自动刷新样式，降低旧浏览器缓存造成的显示异常。
  • 已完成 29 项自动化测试，以及桌面窗口、网页 Life Tracker、直播 Overlay 和打包版 EXE 的实际运行验证。

08

升级说明

  1. 关闭正在运行的旧版 Streaming Tome。
  2. 使用 v1.2 Beta 的 Streaming Tome.exe 替换旧版本并重新启动。
  3. 原有 OBS Browser Source 地址和常用设置可以继续使用。
  4. 若任务栏固定的旧快捷方式仍显示旧图标，请先取消固定，再运行新版 EXE 并重新固定。

Streaming Tome v1.2 Beta focuses on expanded card content, broadcast readability, unified branding, and more efficient live operation. It preserves the local-first workflow, LAN Life Tracker, and OBS Browser Source setup while improving match control, card presentation, and multilingual player-name support.

RELEASE INFORMATION

Released August 20, 2026

Supported platforms: Windows 10 / Windows 11. Streaming Tome remains offline-first and LAN-based; match state is never uploaded to or persisted by an external service.

01

Highlights

  • MPW and AOL card content is now integrated into the local library.
  • Hero portraits, life totals, the timer, and the symmetrical Match Overlay layout have been refined.
  • Card text now renders Markdown correctly and displays Flesh and Blood attribute icons.
  • Branding is unified across desktop windows, web pages, the EXE, and the Windows taskbar.
  • Card Reference Console now loads on demand for a lighter startup.
  • Match Control and Overlay correctly display Chinese, Japanese, Korean, and other non-Latin player names.

02

Card Content

MPW and AOL sets

Card data and images for both sets have been integrated to the existing offline-library standard. They are available in Card Reference Console search, standalone card-image windows, local card-text lookup, hero selection, and Match Overlay portraits.

The local database now contains 2,926 card records and has been checked for missing images, invalid files, and duplicates. Runtime data is fully local and does not require an external card API.

Improved hero portraits

Overlay hero portraits now use a square crop focused on the artwork, without card borders, names, or other printed text, giving broadcasts a more professional tournament look.

03

Match Control and Broadcast Overlay

Redesigned life totals

  • The HP label is replaced by a Health icon positioned according to each player's side.
  • Clear spacing, wider usable areas, and borderless totals reduce clipping and obstruction.
  • Match records move outward to preserve a symmetrical two-player layout.
  • Fixed life-change animations expanding outside their display areas.

Timer and layout

The ROUND TIMER label is larger and easier to read from a distance. Timing, overtime, Untimed Round, themes, custom colors, and size controls remain available.

Multilingual player names

Chinese, Japanese, Korean, and other non-Latin names automatically use Microsoft YaHei to prevent missing glyphs. English-only names keep the original broadcast font, and the selection persists through scaling, theme changes, and match-state synchronization.

04

Card Text Rendering

Markdown parsing

Rules text now correctly renders common Markdown headings, italics, and bold text.

Flesh and Blood attribute icons

Attribute markers are converted to inline icons aligned with the text baseline. This works with English and local translations; updated translation content will follow.

{h} Health{p} Power{i} Intellect{d} Defense{t} Tap{u} Untap{c} Chi{r} Resource

05

Brand Refresh

The new Streaming Tome logo now appears in Match Control, Card Reference Console, card-text windows, the web Life Tracker, browser tabs, Windows windows and taskbar, and the distributed EXE.

A white rounded background preserves contrast on dark interfaces, while a more compact Console logo leaves more space for search. Windows runtime and embedded EXE icons now share the same brand asset and application identity to reduce stale taskbar icons.

06

Startup and Window Management

On-demand Card Reference Console

Streaming Tome now starts with Match Control only. The card database, translations, and Console windows load the first time OPEN CARD CONSOLE is selected, reducing unnecessary startup work.

Independent windows

  • Closing Card Reference Console no longer exits the app or stops Life Tracker.
  • Match Control can reopen it at any time; an open or minimized window is restored to the foreground.
  • OPEN LIFE TRACKER remains available in the Console to return to Match Control.

07

Stability and Compatibility

  • LAN Life Tracker, WebSocket synchronization, and OBS Browser Source URL formats are unchanged.
  • Transparent Overlay backgrounds, the 16:1 ratio, Always on Top, and custom dimensions remain available.
  • Versioned web assets automatically refresh styles after an in-place upgrade and reduce stale-browser-cache issues.
  • The release passed 29 automated tests plus hands-on checks of desktop windows, web Life Tracker, broadcast Overlay, and the packaged EXE.

08

Upgrade Instructions

  1. Close the currently running version of Streaming Tome.
  2. Replace it with the v1.2 Beta Streaming Tome.exe and restart.
  3. Existing OBS Browser Source URLs and commonly used settings remain compatible.
  4. If a pinned taskbar shortcut still shows the old icon, unpin it, launch the new EXE, and pin it again.
