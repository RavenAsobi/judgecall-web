JudgeCall 2.2

Android · APK · 正式版本

JudgeCall 2.2 正式发布。现在可以在 About → Update 下载最新规则内容，更新后继续离线阅读和搜索，无需为每次文档更新重新安装 App。

安装说明

从官网 v2.1.1 直接升级

本版本沿用官网 v2.1.1 的签名，可直接覆盖安装并保留本地裁判记录。若手机提示签名不兼容，请先确认已安装版本的来源，并导出重要记录后再处理。

01

规则内容更新

  • 新增 Usurp the Shadow Throne Release Notes。
  • 内置内容版本 2026.09.22.1，涵盖 CR、TRP、PPG、Release Notes 和 Errata Bulletins。
  • 勘误图片与 TRP 公式随规则内容一同下载，离线时仍可查看。

02

About 页面一键更新

  • 显示当前内容版本、发布日期与最近检查时间。
  • 点击 Update 检查服务器，下载并验证最新内容后自动启用。
  • 下载或验证失败时保留现有内容；启动时可从损坏的内容版本回退。

03

独立内容库

规则内容与个人裁判记录分别存储，更新规则不会替换裁判记录。内置完整规则包，首次启动也可离线使用。

本阶段专注 Android 版本，Windows 开发暂时暂停。

INSTALLATION

Upgrade directly from the official v2.1.1

This release uses the same signing key as the website's v2.1.1 and preserves local judge-call records when installed over it. If Android reports a signature mismatch, check the source of your existing installation and export important records before proceeding.

01

Reference content

  • Added the Usurp the Shadow Throne Release Notes.
  • Bundled content version 2026.09.22.1 covers CR, TRP, PPG, Release Notes, and Errata Bulletins.
  • Errata images and TRP formulas are included with content updates and remain available offline.

02

Update from About

  • View the installed content version, publication date, and last check time.
  • Tap Update to check the server, download and verify new content, and activate it automatically.
  • Failed downloads or verification keep existing content available. Startup can fall back from a damaged content version.

03

Separate content storage

Reference content and personal judge-call records are stored separately, so updating rules does not replace your records. A complete bundled library supports offline use from the first launch.

Development currently focuses on Android; Windows development is paused.
