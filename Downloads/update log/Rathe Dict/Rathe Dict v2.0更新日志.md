# Rathe Dict v2.0更新日志

Rathe Dict v2.0 带来了全新的 **MyList 清单系统、R2D 离线分享机制、卡图分享功能**，并进一步完善搜索逻辑、符号显示与整体 UI 体验。

## 1. 数据更新

- 离线卡牌数据库已更新至 **Mastery Pack: Warrior**。

- 离线卡图资源已同步更新至 **Mastery Pack: Warrior**。

- **Release Notes** 数据已同步更新至 **Mastery Pack: Warrior**。

## 2. 功能更新

### 全新 MyList 功能

新增 **MyList** 清单系统，可用于快速创建和管理自定义卡牌清单。

目前支持：

- 创建、编辑和管理多个 List。

- 为清单中的单卡指定具体印刷版本。

- 将完整 List **生成图片并分享**。

- 将 List **生成 R2D 码**，便于快速分享。

- 支持读取他人分享的 **R2D 码** 导入 List。

- **R2D 码无需联网即可完成数据传递与导入**，适用于网络环境不稳定的场景。

### 卡图保存与分享

新增卡图快捷操作。

在单卡页面中 **长按卡图**，即可：

- 将卡图保存至本地；

- 直接分享到其他应用。

### 搜索逻辑升级

进一步丰富搜索关键词识别逻辑，对常见缩写、简称及模糊搜索进行自动匹配。

例如搜索：

- `cnc`

- `popper`

- `warrior chest`

等关键词时，Rathe Dict 将尝试自动识别对应卡牌，减少输入完整卡名的需要，让移动端查询更加快速。

## 3. 问题修复与体验优化

- 完善各类游戏符号的映射与显示。

- 修复收藏按钮在未选中状态下图标显示错误的问题。

- 优化搜索结果页面返回逻辑：从搜索结果进入单卡详情后再次返回，将恢复至**此前浏览位置**，不再自动回到列表顶部。

- 修复 **True Text** 中部分 Markdown 语法校验及显示异常。

- 移除开发过程中误显示的冗余信息。

- 优化并统一 App 各页面 UI 视觉与交互逻辑。

- 优化 **Filter** 功能，将筛选条件调整为折叠式选项，使界面更加简洁。

**安装 Rathe Dict v2.0 前，请先卸载现有的 1.X 版本。**
