# Lynx Extension v1.0.1／Lynx Deck Check 更新说明

发布日期：2026-11-16

本次说明重点介绍已上线的 Lynx 网页“套牌检查（Deck Check）”视角。Deck Check 功能运行在网页中；插件 v1.0.1 负责提供配对、赛果与可验证的玩家 ID。

## Deck Check 视角

- 点击 Lynx 网页中的用户名，在“巡场裁判”和“套牌检查”视角之间切换；这不会改变登录权限。套牌检查视角以列表显示每桌的桌号、双方玩家、各自累计 DC 次数、积分及已归档的胜／负／平场次。
- DC 是 Deck Check，不是 Drop。DC 次数来自本场赛事已保存的玩家检查记录，跨轮累计；同一玩家在同一轮最多标记一次。
- 点击桌号列表项，可以分别为两位玩家标记套牌检查并记录轮次，查看最近记录，填写各自备注，或打开 FAB／MTG 对应的判罚表单。可为该桌添加补时，默认 10 分钟；已有补时时会提示叠加后的总时长。检查记录、备注和补时保存在服务器。

## 快速筛选与随机抽桌

- 输入“抽选桌数”（默认 1）和“最低分数”（默认 0）。最低分数大于 0 时，双方都须达到门槛；首轮积分按 0 分计算，积分无法匹配的桌台不进入正分门槛候选池。
- “双方均未DC”要求双方都没有检查记录；“仅一方有DC”要求恰好一方有记录；“无限制”不按 DC 历史筛选。这些按钮只筛选随机抽选的候选池，不隐藏列表。
- 未录齐双方玩家或标为 Ghost 的桌台不参与抽选。一次抽选内桌号不重复；抽中的桌台会在列表高亮。候选桌数不足时提示调整条件。

## 与插件及积分结算的配合

- 插件 v1.0.1 预览玩家 ID 覆盖情况，保留可验证的 GEM 和 Melee 玩家 ID；无已验证 ID 时不按姓名伪造。Melee 明确的双方弃权导出为 `LOSSALL`，不再误作平局。
- 插件只读来源页面当前可见桌台。Lynx 每轮首次导入会按 JSON 重设桌数，请先核对完整性。普通 JSON 不会自行开新一轮。
- Lynx 开始下一轮时确认旧轮赛果并累计积分，供 Deck Check 的最低分数筛选使用。插件积分榜导出仅作为核对／恢复备用；管理人员可在“积分校正／恢复”导入，覆盖会留下审计记录。自动积分不代表官方名次。

安装插件：下载并解压 ZIP；在 Chrome 的 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，指向包含 `manifest.json` 的文件夹。升级时建议先停用旧版，验证 v1.0.1 后再移除。
