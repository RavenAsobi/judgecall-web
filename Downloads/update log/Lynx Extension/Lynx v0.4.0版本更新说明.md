# Lynx Extension v0.4.0 版本更新说明

本版聚焦于导入安全：在复制 JSON 前核对桌数与桌号范围，且不再自动猜测“新一轮”。

## 主要变化

- 提取后预览当前页面的桌数、最小和最大桌号；桌号范围有缺号时提示可能存在筛选或分页。确认后才能复制。
- “普通 JSON”不再自动附加新一轮代码头。即使所有桌台未上报，也不会自行推进轮数。
- 只有显式选择“新一轮”并填写 Lynx 赛事设置中的起始桌号，才会导出新一轮代码头。支持正序和倒序桌号。
- 新一轮导出校验桌号连续，且所有桌台未回报、无 Drop、无加时；重复或无效桌号会在复制前拦截。
- GEM、Melee 和 EventLink 原有数据提取能力保留；EventLink 的 0:0 DRAW 原始比分仍可导出。

## 使用提醒

插件仅读取来源网站当前页面显示的桌台，不会自动跨分页或取消筛选。Lynx 每轮首次导入会按 JSON 桌号清单重设总桌数，因此首次导入前必须确认页面包含该轮全部桌台。首轮首次导入使用普通 JSON。

下载 ZIP 后解压，在 Chrome 的 `chrome://extensions` 开启开发者模式，通过“加载已解压的扩展程序”选择含 `manifest.json` 的文件夹。升级时建议先停用 v0.3.0，确认新版正常后再移除旧版。

> 本次发布范围是 Download 页和插件安装包。Lynx 网页端的 0:0 DRAW 已回报显示修正仍取决于网页版本，不随本次下载页发布自动上线。
